# Sketchbot: sample React site

A small single-page landing site built with React and Vite, themed around the drawing robot in this repository.

It includes:

- A hero section with a random drawing-prompt generator
- A working drawing pad (HTML canvas) with colors, pen size and clear
- A features grid
- Pricing cards with a monthly/yearly toggle
- An FAQ accordion
- A waitlist form that confirms in the page (demo only, nothing is sent)

## Run it

```bash
cd sample-react-site
npm install
npm run dev      # start the dev server at http://localhost:5173
npm run build    # build static files into dist/
npm run preview  # serve the built files
```
